FUNCIONALIDADES DE LA APLICACION VAFCA
======================================

Este documento resume lo que se puede hacer actualmente con la aplicacion,
segun la estructura y el codigo del proyecto.


1. Proposito general
--------------------

La aplicacion es una herramienta web para explorar datos de conectividad
funcional. Trabaja con datasets en formato JSON que contienen matrices de
conectividad, informacion de atlas, ROIs, catalogos de poblaciones, medidas,
estadisticas, bandas de frecuencia y configuraciones necesarias para visualizar
y comparar redes.

La interfaz esta organizada en tres areas principales:

- Network Visualization: exploracion visual de matrices y redes.
- Atlas: gestion y visualizacion de ROIs del atlas.
- Selected Links: revision y exportacion de enlaces seleccionados.


2. Carga y gestion de datos
---------------------------

La aplicacion permite cargar un bundle JSON de conectividad funcional en el
formato fc-connectivity-v1.0. La carga se realiza desde el modal Data, mediante
una zona de drag and drop.

Durante la carga, la aplicacion valida el archivo y comprueba aspectos como:

- estructura general del JSON
- existencia de matrices
- dimensiones de las matrices
- orden de ROIs
- valores numericos validos
- compatibilidad con el formato esperado
- presencia de catalogos de poblaciones, medidas, estadisticas y bandas

Si el archivo es valido, las matrices se cargan en memoria para ser usadas por
las visualizaciones y calculos. Si existen errores o advertencias, la interfaz
los muestra al usuario indicando el origen y la causa.

Desde el mismo panel de datos se puede:

- ver el numero total de matrices cargadas
- consultar un resumen por medida, estadistica y poblacion
- ver el numero de poblaciones, medidas, estadisticas y bandas
- descargar el dataset actual como JSON
- reemplazar el dataset cargando otro bundle compatible

La aplicacion tambien carga automaticamente datos de ejemplo al iniciar, segun
la configuracion definida en el proyecto.


3. Gestion de catalogos
-----------------------

El modal Data incluye una pestana Catalogs para editar metadatos del dataset.

Se pueden modificar catalogos de:

- poblaciones
- medidas
- estadisticas
- bandas de frecuencia

Para cada elemento de catalogo se pueden editar campos como:

- etiqueta visible
- descripcion
- estado activo/inactivo

En el caso de las medidas, tambien se pueden editar valores minimo y maximo.
En el caso de las bandas, la interfaz muestra su rango de frecuencia.

Estos catalogos afectan a como se muestran las opciones y etiquetas en el resto
de la aplicacion.


4. Seleccion de matrices y creacion de vistas
---------------------------------------------

En la pestana Network Visualization, la aplicacion permite seleccionar matrices
usando filtros de dominio:

- tipo de vista
- poblacion o conjunto de poblaciones
- medida
- estadistica
- banda
- matriz concreta

Una vez seleccionada una matriz, se puede anadir una vista al panel de
visualizacion. La aplicacion permite tener multiples vistas simultaneas.

Los tipos de vista disponibles son:

- Matrix: heatmap de matriz de conectividad
- Circular: visualizacion circular de red
- Node-Link: visualizacion clasica de red con nodos y enlaces

Cada vista se muestra como un panel dentro de un grid. Los paneles pueden
reorganizarse y redimensionarse. Tambien se pueden eliminar individualmente.


5. Visualizacion tipo matriz
----------------------------

La vista Matrix representa los valores de conectividad como un heatmap.

Permite:

- ver valores por celda
- mostrar etiquetas de filas y columnas
- aplicar escalas de color segun el rango de valores
- usar rangos comparables entre matrices cuando corresponde
- mostrar tooltips con informacion de la celda
- seleccionar celdas/enlaces
- hacer brush zoom sobre una region de la matriz
- usar etiquetas seleccionadas como objetivo de zoom
- aplicar filtros de valores

La matriz tambien se integra con la seleccion global de enlaces, de forma que
las celdas seleccionadas pueden aparecer despues en la pestana Selected Links.


6. Visualizacion circular
-------------------------

La vista Circular representa la matriz como una red organizada alrededor de un
circulo.

Permite:

- representar ROIs como nodos
- representar conexiones como enlaces
- colorear nodos segun campos del atlas
- ajustar grosores de enlaces segun los valores de conectividad
- ocultar nodos aislados
- usar agrupaciones jerarquicas para ordenar nodos
- mostrar tooltips en nodos y enlaces
- seleccionar enlaces
- seleccionar etiquetas para zoom
- hacer brush zoom
- usar zoom geometrico

La vista circular utiliza la configuracion de jerarquia y paleta definida en
Visualization Settings.


7. Visualizacion node-link
--------------------------

La vista Node-Link representa la matriz como una red clasica de nodos y enlaces.

Permite:

- visualizar conexiones entre ROIs en un grafo
- calcular una disposicion visual con D3
- colorear nodos segun campos del atlas
- ajustar grosor de enlaces segun valores de matriz
- ocultar nodos aislados
- mostrar tooltips
- seleccionar enlaces
- hacer zoom por seleccion
- usar zoom geometrico
- destacar enlaces o nodos al pasar el cursor

Esta vista esta pensada para explorar relaciones topologicas de forma mas libre
que en la matriz o en la vista circular.


8. Acciones disponibles por visualizacion
-----------------------------------------

Cada panel de visualizacion incluye acciones propias.

Se puede:

- descargar la visualizacion como SVG
- descargar la visualizacion como PNG a escala 2x
- descargar la visualizacion como PNG a escala 4x
- descargar la visualizacion como JPEG a escala 2x
- activar o desactivar brush zoom
- activar o desactivar zoom geometrico en vistas de red
- hacer zoom hacia las etiquetas seleccionadas
- limpiar la seleccion de nodos
- volver atras en el historial de zoom
- avanzar en el historial de zoom
- configurar si la vista actua como filtro de nodos o enlaces
- recargar una vista si ha habido algun problema de carga
- cambiar el tipo de vista del panel


9. Zoom coordinado
------------------

La aplicacion permite coordinar el zoom entre visualizaciones. Esta opcion se
activa o desactiva desde Visualization Settings.

Cuando el zoom coordinado esta activo, una seleccion de etiquetas o una region
seleccionada en una vista puede aplicarse tambien a otras vistas compatibles.

La aplicacion mantiene historial de zoom, por lo que se puede navegar hacia
atras y hacia delante entre selecciones previas.


10. Filtros de enlaces
----------------------

El modal Filter permite crear filtros de enlaces basados en valores de matrices.

Hay dos modos principales:

- Original: filtra enlaces ROI-ROI de matrices originales o derivadas no
  agregadas.
- Aggregated: filtra enlaces entre grupos de ROIs en matrices reducidas o
  agregadas.

El editor de filtros permite:

- seleccionar una matriz como fuente de condicion
- definir rangos numericos
- combinar reglas
- crear grupos logicos
- aplicar condiciones sobre distintos tipos de matriz
- validar el filtro antes de aplicarlo
- ver advertencias y errores de configuracion
- previsualizar cuantos enlaces quedan seleccionados
- limpiar el filtro actual
- eliminar el filtro activo

El filtro aplicado afecta a las visualizaciones de red y matriz, reduciendo los
enlaces visibles segun las condiciones configuradas.


11. Uso de vistas como filtros
------------------------------

Cada visualizacion puede configurarse para actuar como filtro de otras vistas.

Una vista puede usarse como:

- filtro de nodos
- filtro de enlaces

Esto permite flujos de exploracion comparativa. Por ejemplo, una matriz puede
definir un rango de enlaces relevantes y otras vistas pueden mostrar solo los
nodos o enlaces compatibles con esa seleccion.


12. Configuracion general de visualizacion
------------------------------------------

El modal Visualization Settings permite configurar opciones globales.

Incluye:

- modo de rango para escalas y filtros
- inclusion o exclusion de diagonal en rangos
- zoom coordinado
- ocultacion de nodos aislados
- campos usados para colorear nodos y ROIs
- paleta categorica D3
- orden jerarquico para vistas circulares
- orden jerarquico para matrices

La configuracion de paleta permite elegir uno o varios campos del atlas. El
orden de esos campos importa, porque define categorias combinadas. Tambien se
puede ver una previsualizacion de categorias y colores.


13. Gestion y visualizacion del atlas
-------------------------------------

La pestana Atlas permite trabajar con ROIs y atlas.

Desde esta seccion se puede:

- cargar un atlas JSON
- ver metadatos del atlas
- limpiar el atlas subido
- alternar entre atlas con mesh points y sin mesh points
- visualizar ROIs en un visor 3D cuando hay datos suficientes
- buscar ROIs por etiqueta o id
- agrupar ROIs por campos comunes del atlas
- filtrar ROIs por valores de grupo
- activar o desactivar ROIs individualmente
- activar todos los ROIs
- desactivar todos los ROIs
- reorganizar campos de agrupacion
- cambiar la altura del visor 3D

El visor 3D incluye posiciones de camara predefinidas:

- Front
- Right
- Top
- Left

Tambien permite ocultar un ROI con doble click.


14. ROIs activos e impacto en visualizaciones
---------------------------------------------

Los ROIs pueden estar activos o inactivos. Esta seleccion afecta a las
visualizaciones y a ciertos calculos.

Cuando un ROI esta desactivado:

- puede excluirse de visualizaciones
- puede excluirse de agregaciones
- puede afectar al conjunto de nodos visibles
- puede hacer que matrices agregadas existentes queden obsoletas respecto a la
  seleccion actual de ROIs

La aplicacion informa cuando hay ROIs inactivos que seran excluidos de una
agregacion.


15. Calculo de matrices derivadas
---------------------------------

El modal Compute permite crear matrices derivadas a partir de las matrices
cargadas.

La disponibilidad de cada metodo depende de que existan las matrices necesarias
en el dataset. La aplicacion muestra solo los metodos que puede calcular con la
informacion disponible.

Los metodos soportados incluyen:

- Subject vs reference population z-score
- Population vs reference population z-score
- Difference between population means
- Cohen's d between populations
- Two-sample Z test
- Welch t-test

Algunos metodos tambien permiten generar salidas asociadas, como:

- Student t asociado a Cohen's d
- p-value asociado a Cohen's d
- p-value del Z-test
- p-value del test de Welch

Antes de calcular, la aplicacion muestra una previsualizacion con:

- metodo
- banda
- medida
- poblacion o sujeto izquierdo/objetivo
- poblacion derecha/control
- estadistica de salida
- estado de la combinacion

Las combinaciones sin datos suficientes se omiten y se informa al usuario.


16. Agregacion de matrices por grupos de ROIs
---------------------------------------------

El modal Compute tambien permite crear matrices agregadas.

La agregacion utiliza la agrupacion actual configurada en Visualization Settings.
Por ejemplo, si los ROIs estan agrupados por red, region, hemisferio u otro
campo del atlas, la aplicacion puede construir una matriz reducida grupo-grupo.

La agregacion:

- parte de una o varias matrices ROI-ROI
- agrupa ROIs activos segun campos del atlas
- excluye ROIs inactivos
- calcula valores medios validos entre grupos
- genera una matriz reducida
- reutiliza matrices agregadas equivalentes si ya existen

La aplicacion muestra advertencias cuando:

- hay ROIs sin el campo de agrupacion seleccionado
- hay ROIs inactivos excluidos
- ya existen matrices agregadas que quedaron obsoletas por cambios en ROIs
  activos

La agregacion resume valores ROI-ROI existentes. No recalcula PLV ni otras
medidas desde series temporales originales.


17. Selected Links
------------------

La pestana Selected Links permite revisar enlaces seleccionados desde las
visualizaciones.

Desde esta seccion se puede:

- ver una tabla de enlaces seleccionados
- eliminar enlaces individuales
- limpiar toda la seleccion
- seleccionar enlaces para resaltarlos en el atlas
- anadir matrices adicionales como columnas de valores
- comparar el valor de un mismo enlace en varias matrices
- ordenar columnas numericas
- ver valores no disponibles como n/a

La seccion incluye tambien una vista de atlas asociada para visualizar los
enlaces marcados.


18. Exportacion de enlaces seleccionados
----------------------------------------

Los enlaces seleccionados se pueden descargar como JSON.

Hay dos modos de exportacion:

- Download all available matrices: exporta valores para todas las matrices
  disponibles.
- Download selected matrices: exporta solo las matrices seleccionadas en el
  panel.

El archivo exportado incluye:

- fecha de exportacion
- modo de exportacion
- numero de enlaces
- numero de capas o matrices
- lista de capas exportadas
- valores de los enlaces por matriz

Si el usuario ha marcado enlaces concretos en la tabla, se exportan esos enlaces.
Si no hay marcas, se exporta toda la lista de enlaces seleccionados.


19. Exportacion de visualizaciones
----------------------------------

Las visualizaciones pueden exportarse desde cada panel.

Formatos soportados:

- SVG
- PNG 2x
- PNG 4x
- JPEG 2x

Esto permite guardar graficos para informes, analisis externo o documentacion.


20. Formatos y ejemplos disponibles
-----------------------------------

El proyecto incluye documentacion del formato de matrices en MATRIX_FORMAT.md.
Tambien incluye varios datasets de ejemplo en public/data/examples.

Entre los ejemplos hay casos como:

- una poblacion control
- un sujeto de estudio
- poblacion y sujeto
- dos poblaciones
- cambios de banda
- cambios de medida
- orden ROI incompatible
- formato triangular superior
- formato triangular inferior
- datos con y sin z-score
- casos invalidos para probar validaciones

Estos ejemplos sirven para probar la aplicacion y sus validaciones.


21. Limitaciones observadas
---------------------------

Segun el codigo actual, la aplicacion parece ser frontend-only. No se observa
un backend propio.

Las matrices se almacenan en memoria durante la sesion de navegador. Esto
significa que el almacenamiento no parece persistir automaticamente entre
recargas salvo que se vuelva a cargar el dataset o se use la configuracion de
datos iniciales.

El README del proyecto todavia es el README generico de Vite, por lo que no
documenta las funcionalidades reales de la aplicacion.


22. Resumen ejecutivo
---------------------

En resumen, esta aplicacion permite cargar datasets de conectividad funcional,
validarlos, explorar sus matrices con visualizaciones interactivas, gestionar
ROIs y atlas, aplicar filtros complejos de enlaces, calcular matrices derivadas,
agregar matrices por grupos de ROIs, seleccionar enlaces relevantes y exportar
tanto visualizaciones como datos seleccionados.

Es una herramienta orientada a la exploracion visual y comparativa de redes de
conectividad funcional, con especial atencion a matrices, atlas, ROIs,
poblaciones, sujetos, medidas, estadisticas y bandas de frecuencia.
